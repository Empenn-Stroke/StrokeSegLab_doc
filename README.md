# StrokeSegLab Documentation Guide

This document explains how to generate and view the **HTML API documentation** for the **StrokeSegLab** project using **[Doxygen](https://www.doxygen.nl/)** and **Doxywizard**.

---

## 📦 Requirements

Make sure you have **Doxygen** installed:

```bash
doxygen --version
```

🏗️ Generate the Documentation

   1. Open Doxywizard
   2. Load the Doxyfile, Click “File → Open” and select the Doxyfile located in the repository root.
   3. Run Doxygen;Go to the “Run” tab and click the green “Run doxygen” button.
